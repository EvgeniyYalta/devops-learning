# Day 8 — Bash: анализ логов Linux

Дата: 18.09.2026

## Цель дня

Научиться работать с системными логами Linux
и автоматизировать их анализ с помощью Bash.

В течение дня изучаем:

- каталог `/var/log`;
- системные журналы Linux;
- SSH-логи;
- команду `grep`;
- конвейер `|`;
- команду `wc`;
- команду `awk`;
- команду `sort`;
- команду `uniq`;
- извлечение отдельных полей из строк;
- подсчёт событий;
- поиск IP-адресов;
- Bash-переменные;
- автоматизацию анализа логов;
- коды завершения `0` и `1`.
