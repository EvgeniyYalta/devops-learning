# Day 9 — Bash: функции, аргументы и автоматизация

Дата: 19.09.2026

## Цель дня

Изучить функции Bash, передачу аргументов, локальные переменные
и применение функций для автоматизации типовых DevOps-задач.

---

## Практика 1 — функции Bash

Создали первый скрипт с Bash-функцией `hello()`.

Научились создавать функцию, вызывать её несколько раз
и использовать функции для повторного выполнения одного блока кода
без его дублирования.

Созданный файл:

`function_demo.sh`

---

## Практика 2 — аргументы функций

Дополнили работу с функциями и научились передавать им аргументы.

Изучили `$1` и `$2` для получения первого и второго аргумента,
а также `local` для создания локальных переменных функции.

На практике одна функция использовалась с разными именами
и ролями.

Созданный файл:

`function_demo.sh`

---

## Практика 3 — проверка Linux-сервисов через функцию

Создали функцию `check_service()`, которая получает имя сервиса
через аргумент и проверяет его состояние с помощью `systemctl`.

Проверили работу функции на сервисах `ssh` и `chrony`.

Дополнительно специально остановили `chrony`, убедились,
что функция обнаруживает неисправность, после чего снова запустили
сервис и проверили его восстановление.

Созданный файл:

`service_function.sh`

---

## Практика 4 — проверка файлов и директорий

Создали функцию `check_path()` для проверки указанных путей.

Научились определять:

- существует ли обычный файл;
- существует ли директория;
- отсутствует ли указанный путь.

На практике проверили `/etc/hosts`, `/tmp` и специально
несуществующий путь.

Созданный файл:

`path_function.sh`

---

## Практика 5 — объединение функций

Объединили несколько функций в один диагностический скрипт.

Использовали функции проверки сервисов и файловой системы,
добавили счётчик ошибок и общий результат проверки сервера.

Проверили два состояния:

- сервер без ошибок — `HEALTHY`, exit code `0`;
- остановленный `chrony` — `WARNING`, exit code `1`.

После проверки сервис был восстановлен.

Созданный файл:

`diagnostic_functions.sh`

---

## Практика 6 — итоговая автоматизация

Создали итоговую Bash-утилиту диагностики сервера.

Скрипт принимает имена сервисов через аргументы командной строки,
проверяет их состояние, выполняет проверки файловой системы,
подсчитывает ошибки и формирует общий результат.

Изучили использование:

- `$#` — количество аргументов;
- `$@` — все переданные аргументы;
- `$0` — имя скрипта;
- цикла `for`;
- функций, вызывающих другие функции;
- обработки отсутствующих аргументов;
- exit-кодов.

Проверили работу скрипта с двумя сервисами, одним сервисом,
несуществующим сервисом и без аргументов.

Созданный файл:

`server_diagnostic.sh`

---

За Day 9 перешли от простых Bash-функций к созданию
