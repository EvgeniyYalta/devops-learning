# День 23 — Docker Healthcheck и Restart Policies

## Цель

Научиться проверять состояние контейнеров Docker, настраивать healthcheck, диагностировать сбои и управлять автоматическим перезапуском контейнеров.

## Практика 1. Подготовка проекта

- Создан каталог `~/docker-lab/day23-healthcheck`.
- Создан `compose.yaml` с сервисом Nginx.
- Настроен healthcheck через `curl`.
- Проверена доступность порта 8088.

## Практика 2. Проверка работоспособности

- Контейнер запущен через Docker Compose.
- Проверены `docker compose ps` и `docker inspect`.
- Получен статус `running` и `healthy`.
- HTTP-запрос завершился кодом `200 OK`.

## Практика 3. Имитация остановки сервиса

- Выполнена остановка Nginx внутри контейнера.
- Проверено состояние `exited` и `unhealthy`.
- HTTP-запрос подтвердил недоступность сервиса.

## Практика 4. Имитация сбоя healthcheck

- Временно удалена главная страница Nginx.
- Получен HTTP-код `403 Forbidden`.
- Docker определил состояние `unhealthy`.
- После восстановления файла контейнер вернулся в `healthy`.

## Практика 5. Диагностика healthcheck

- Изучены `.State.Health`, история проверок и коды завершения.
- Проверены параметры `interval`, `timeout`, `retries`, `start_period`.
- Проверена первоначальная политика перезапуска `no`.

## Практика 6. Настройка автоматического перезапуска

- Настроена политика `unless-stopped`.
- Проверено поведение контейнера после принудительной остановки.
- Подтверждён автоматический перезапуск после завершения основного процесса.
- Настройка закреплена в `compose.yaml`.
- Контейнер успешно пересоздан.

## Практика 7. Анализ событий Docker

- Изучена команда `docker events`.
- Найдены события `die`, `start`, `stop`, `destroy` и `health_status`.
- Выполнена фильтрация событий по контейнеру и типу.
- Проверены события завершения и запуска контейнера.

## Практика 8. Финальная проверка

- `docker compose ps` — контейнер работает.
- `docker inspect` — `running`, `healthy`.
- Политика перезапуска — `unless-stopped`.
- HTTP-запрос на порт 8088 — `200 OK`.

## Созданные файлы

- `~/docker-lab/day23-healthcheck/compose.yaml`
- `~/devops-learning/docker/day23.md`

## Итог дня

Освоены Docker healthcheck, диагностика неисправностей, события жизненного цикла контейнера и политики автоматического перезапуска.

**Результат:** Nginx работает на порту 8088, Docker определяет контейнер как `healthy`, настроена политика `unless-stopped`.
