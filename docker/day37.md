# День 37 — GitHub Actions: условное выполнение jobs

## Цель дня

Научиться управлять запуском целых заданий GitHub Actions с помощью `if`, `needs` и параметров `workflow_dispatch`.

### Практика 1. Проверка существующего workflow

- Проверен текущий файл `.github/workflows/first-ci.yml`.
- Подтверждено наличие заданий `basic-check` и `validation`.
- Проверена передача результатов между заданиями через `outputs`.
- Проверено чистое состояние Git-репозитория.

**Результат:** существующая конфигурация готова к расширению.

### Практика 2. Добавление условного задания

- Добавлен job `staging-check`.
- Настроена зависимость `needs: validation`.
- Добавлено условие `if: ${{ inputs.target_environment == 'staging' }}`.
- Добавлен шаг `Check staging job` с диагностическими сообщениями.
- Проверены изменения с помощью `git diff --check` и `git diff`.

**Результат:** добавлено задание, которое выполняется только для окружения `staging` после успешного завершения `validation`.
