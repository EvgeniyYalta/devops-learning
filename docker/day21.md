# День 21 — Docker Compose: управление ресурсами

## Цель

Изучить ограничение CPU и оперативной памяти контейнеров, мониторинг потребления ресурсов, диагностику завершения процессов и изменение лимитов Docker.

## Практика 1. Проверка окружения

- Проверены Docker Engine 29.8.1 и Docker Compose 5.5.1.
- Проверено состояние работающих контейнеров.
- Проверены свободная оперативная память, количество процессоров и нагрузка сервера.

## Практика 2. Подготовка проекта

- Создан каталог `~/docker-lab/day21-resources`.
- Проверена доступность порта 8087.
- Создан `compose.yaml` с сервисом Nginx.
- Настроены ограничения: 0.5 CPU и 128 MiB RAM.
- Конфигурация проверена командой `docker compose config`.

## Практика 3. Запуск контейнера и проверка лимитов

- Контейнер `day21-nginx` запущен через Docker Compose.
- Проверен HTTP-ответ `200 OK` на порту 8087.
- Через `docker inspect` проверены ограничения памяти и CPU.
- Подтверждены `Memory=134217728` и `NanoCPUs=500000000`.

## Практика 4. Мониторинг ресурсов

- Изучены показатели `docker stats`: CPU, RAM, сеть, дисковые операции и процессы.
- Проверены cgroups v2 и файл `/sys/fs/cgroup/cpu.max`.
- Проверено потребление памяти контейнером.
- Создана кратковременная нагрузка на CPU.
- Зафиксировано повышение потребления CPU примерно до 49%.

## Практика 5. Ограничение оперативной памяти

- Создан тестовый контейнер `day21-memory-test` на Alpine.
- Установлено ограничение памяти 64 MiB.
- Проверены настройки через `docker inspect`.
- Подтверждён лимит `64MiB` через `docker stats`.

## Практика 6. Диагностика завершения контейнера

- Запущен `day21-oom-test` с ограничением памяти 64 MiB и swap 64 MiB.
- Тестовый Python-процесс пытался выделить 128 MiB памяти.
- Получены `Status=exited`, `ExitCode=137`, `OOMKilled=false`.
- Изучены `docker inspect`, `docker logs` и состояние контейнеров.
- Причина завершения по полученным данным однозначно не установлена.
- Временные контейнеры удалены.
- Проверена работоспособность основного Nginx.

## Практика 7. Динамическое изменение ресурсов

- Командой `docker update` увеличен лимит памяти до 256 MiB.
- Лимит CPU увеличен до одного ядра.
- Подтверждены `Memory=268435456` и `NanoCPUs=1000000000`.
- Проверены новые ограничения через `docker stats`.
- Nginx продолжил работу и возвращал `200 OK`.

## Практика 8. Синхронизация Docker Compose

- В `compose.yaml` установлены `cpus: 1.0` и `mem_limit: 256m`.
- Конфигурация успешно проверена.
- Контейнер пересоздан через `docker compose up -d --force-recreate`.
- Проверено сохранение новых ограничений после пересоздания.
- Подтверждён HTTP-ответ `200 OK`.
- Итоговая конфигурация прошла проверку `docker compose config --quiet`.

## Созданные файлы

- `~/docker-lab/day21-resources/compose.yaml`
- `~/devops-learning/docker/day21.md`

## Итог дня

Освоены ограничения CPU и RAM, мониторинг ресурсов через Docker Stats, диагностика завершения контейнеров, динамическое изменение лимитов и управление ограничениями через Docker Compose.

**Результат:** контейнер Nginx успешно работает на порту 8087 с ограничениями 1 CPU и 256 MiB RAM. Конфигурация проверена, пересоздание выполнено успешно, HTTP-ответ — `200 OK`.
