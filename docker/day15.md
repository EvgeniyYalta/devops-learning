
# День 15 — Nginx: виртуальные хосты и конфигурация

## Цель
Научиться обслуживать несколько сайтов через один Nginx, настраивать виртуальные хосты, сервер по умолчанию, HTTP-логирование и сохранять конфигурацию вне контейнера.

## Практика 1 — Подготовка окружения
- Проверена доступность Docker и порта 8081.
- Подготовлен каталог `~/docker-lab/nginx-day15/`.
- Созданы каталоги `conf.d`, `site1`, `site2`.
- Созданы HTML-страницы для двух сайтов.

## Практика 2 — Виртуальные хосты
- Созданы конфигурации `site1.conf` и `site2.conf`.
- Настроены `server_name`, `root`, `index` и `try_files`.
- Запущен контейнер `nginx-day15` с пробросом порта `8081:80`.
- Проверена конфигурация командой `nginx -t`.
- Через HTTP-заголовок `Host` проверена маршрутизация двух сайтов.
- Оба сайта возвращают `200 OK` и собственные HTML-страницы.

## Практика 3 — Сервер по умолчанию
- Проверено поведение Nginx при запросах к неизвестным доменам.
- Создан `00-default.conf` с директивой `default_server`.
- Настроен ответ `404 Not Found` для неизвестных доменов.
- Выполнена перезагрузка Nginx без остановки контейнера.
- Подтверждена корректная маршрутизация известных и неизвестных доменов.

## Практика 4 — Логирование виртуальных хостов
- Изучены директивы `log_format`, `access_log`, `error_log`.
- Создан `00-logging.conf` с форматом `vhost`.
- Добавлены поля IP клиента, Host, server_name, HTTP-запрос и статус.
- Проверена конфигурация и выполнен `nginx -s reload`.
- В журнале подтверждены запросы к обоим сайтам и неизвестному домену.

## Практика 5 — Сохранность конфигурации
- Проверены четыре конфигурационных файла на сервере.
- Проверены три bind mount в режиме `ro`.
- Контейнер `nginx-day15` удалён и создан заново.
- Подтверждена сохранность конфигурации и HTML-страниц.
- После пересоздания проверены ответы: site1 — 200, site2 — 200, unknown — 404.

## Созданные файлы
- `~/docker-lab/nginx-day15/conf.d/site1.conf`
- `~/docker-lab/nginx-day15/conf.d/site2.conf`
- `~/docker-lab/nginx-day15/conf.d/00-default.conf`
- `~/docker-lab/nginx-day15/conf.d/00-logging.conf`
- `~/docker-lab/nginx-day15/site1/index.html`
- `~/docker-lab/nginx-day15/site2/index.html`
- `~/devops-learning/docker/day15.md`

## Итог дня
Освоена настройка нескольких виртуальных хостов в одном Nginx, маршрутизация по заголовку Host, обработка неизвестных доменов, расширенное логирование и восстановление конфигурации через bind mounts.

## Результат
Рабочий Nginx обслуживает два независимых сайта через порт 8081. Неизвестные домены получают HTTP 404. Конфигурация сохраняется при пересоздании контейнера.
