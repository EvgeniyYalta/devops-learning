# День 17 — Docker Compose: управление многоконтейнерным приложением

## Цель
Освоить Docker Compose для развёртывания и управления приложением из нескольких контейнеров, изучить сервисы, сети, DNS, логи и жизненный цикл проекта.

## Практика 1. Проверка окружения
- Проверены Docker Engine 29.8.1 и Docker Compose 5.5.1.
- Проверены существующие контейнеры.
- Установлено, что порт 8083 свободен.

## Практика 2. Создание проекта Docker Compose
- Создан каталог `~/docker-lab/day17-compose`.
- Созданы `compose.yaml` и `nginx/default.conf`.
- В Compose описаны сервисы `backend` и `nginx`.
- Backend использует образ `hashicorp/http-echo:1.0.0`.
- Nginx использует образ `nginx:latest`.
- Настроены порт `8083:80`, bind mount конфигурации, зависимость `depends_on` и сеть `app-network`.
- Проверена конфигурация командой `docker compose config`.

## Практика 3. Запуск многоконтейнерного приложения
- Проект запущен командой `docker compose up -d`.
- Проверено состояние сервисов через `docker compose ps`.
- Проверена работа Nginx как reverse proxy.
- HTTP-запрос вернул `200 OK` и `Hello from Docker Compose`.

## Практика 4. Docker Compose DNS и networking
- Проверено создание сети `day17-compose_app-network`.
- Проверено DNS-разрешение имени `backend` внутри Nginx.
- Backend получил IP `172.20.0.2`, Nginx — `172.20.0.3`.
- Подтверждено взаимодействие контейнеров по имени сервиса.

## Практика 5. Просмотр логов
- Изучена команда `docker compose logs`.
- Просмотрены общие логи проекта.
- Отдельно просмотрены логи `nginx` и `backend`.
- Подтверждена обработка HTTP-запроса со статусом `200`.

## Практика 6. Управление отдельными сервисами
- Backend остановлен командой `docker compose stop backend`.
- Проверено, что Nginx продолжает работать.
- При недоступном backend получен `502 Bad Gateway`.
- Backend восстановлен командой `docker compose start backend`.
- После восстановления получен `200 OK`.
- Проверен перезапуск backend командой `docker compose restart backend` без перезапуска Nginx.

## Практика 7. Остановка, удаление и повторное развёртывание
- Оба сервиса остановлены командой `docker compose stop`.
- Контейнеры и сеть удалены командой `docker compose down`.
- Подтверждено сохранение конфигурационных файлов проекта.
- Выполнено повторное развёртывание командой `docker compose up -d`.
- Проверены работа обоих контейнеров, восстановление сети и HTTP-ответ `200 OK`.

## Созданные файлы
- `~/docker-lab/day17-compose/compose.yaml`
- `~/docker-lab/day17-compose/nginx/default.conf`
- `~/devops-learning/docker/day17.md`

## Итог дня
Освоены основы Docker Compose: описание многоконтейнерного приложения, настройка reverse proxy, взаимодействие контейнеров через Docker DNS, просмотр логов, остановка и перезапуск сервисов, диагностика отказа backend и восстановление приложения из конфигурационных файлов.

**Результат:** приложение из Nginx и backend успешно развёрнуто и работает через порт 8083.
