# День 49 — GitHub Actions: Pull Request CI

## Цель дня

Настроить автоматический запуск CI при создании Pull Request
и проверить полный цикл интеграции изменений в main.

### Практика 1. Проверка существующего workflow

Проверена текущая конфигурация GitHub Actions.
Установлено наличие триггеров push и workflow_dispatch.
Триггер pull_request отсутствовал.

```bash
git status --short # Проверка состояния репозитория
git log -1 --oneline # Проверка последнего коммита
grep -n -A 25 '^on:' .github/workflows/first-ci.yml # Проверка триггеров
```

### Практика 2. Настройка триггера pull_request

В файл .github/workflows/first-ci.yml добавлен триггер:

```yaml
  pull_request:
    branches:
      - main
```

Настроен автоматический запуск CI для Pull Request,
направленных в ветку main.

```bash
git diff --check # Проверка форматирования изменений
git diff -- .github/workflows/first-ci.yml # Просмотр изменений
```

### Практика 3. Публикация и проверка CI

Изменения конфигурации отправлены в main.
Коммит: 926c9ba.

Запуск GitHub Actions №87:
- Статус: Success.
- Время выполнения: 15 секунд.
- Все необходимые проверки выполнены.
- Артефакт bash-test-report создан.

### Практика 4. Проверка запуска CI через Pull Request

Создана отдельная тестовая ветка.

```bash
git switch -c day49-pr-ci-test # Создание тестовой ветки
git commit --allow-empty -m "Day 49: Test pull request CI" # Создание пустого коммита
git push -u origin day49-pr-ci-test # Публикация тестовой ветки
```

Создан Pull Request №5 из day49-pr-ci-test в main.

Проверено автоматическое выполнение CI по событию
pull_request.

Результат:
- 5 успешных проверок.
- 1 пропущенная проверка staging-check.
- Конфликты с main отсутствуют.

### Практика 5. Завершение Pull Request и итоговая проверка CI

Pull Request №5 успешно объединён с main.
Merge commit: adf4e1a.

После слияния автоматически запущен CI №89:
- Статус: Success.
- Время выполнения: 21 секунда.
- Артефакт bash-test-report создан.

Удалена удалённая тестовая ветка.
Выполнена синхронизация локального репозитория.

```bash
git switch main # Переключение на основную ветку
git pull --ff-only # Получение изменений после merge
git branch -d day49-pr-ci-test # Удаление локальной тестовой ветки
git fetch --prune # Очистка устаревших ссылок
git branch -a # Проверка списка веток
git status # Проверка состояния репозитория
git log -3 --oneline # Проверка истории коммитов
```
