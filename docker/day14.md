# День 14 — Nginx: HTTP, конфигурация и диагностика

## Цель
Изучить работу Nginx в Docker, HTTP-запросы и ответы, диагностику ошибок, настройку конфигурации и сохранение её через bind mount.

### Практика 1. Образ Nginx
Проверен локальный образ `nginx:latest` через `docker images`.

### Практика 2. Запуск контейнера
Создан контейнер `nginx-day14`. Проверено его состояние через `docker ps`.

### Практика 3. Доступность HTTP
Проверены опубликованные порты. Установлено, что без `-p` веб-сервер внутри контейнера недоступен через `localhost:80` хоста. Контейнер пересоздан с пробросом `8080:80`.

### Практика 4. HTTP-запросы
Через `curl -I` и `curl` проверены заголовки и содержимое страницы Nginx. Получен ответ `200 OK`.

### Практика 5. Логи и жизненный цикл
Изучены `docker logs`, остановка и повторный запуск контейнера. Проверены записи HTTP-запросов и корректное завершение процессов Nginx.

### Практика 6. HTTP-коды и права доступа
Проверены ответы `200 OK`, `404 Not Found` и `403 Forbidden`. Создан тестовый файл `secret.txt`, изменены его права, изучена реакция Nginx. После проверки файл удалён.

### Практика 7. Конфигурация Nginx
Изучен `/etc/nginx/conf.d/default.conf`: директивы `server`, `listen`, `server_name`, `location`, `root`, `index` и `error_page`.

### Практика 8. Изменение страницы и reload
Изменён `index.html`, получена страница `DevOps Nginx Lab - Day 14`. Выполнены `nginx -t` и `nginx -s reload`, проверен ответ HTTP.

### Практика 9. Health endpoint и диагностика логов
Создан конфигурационный фрагмент `health.location` для `/health`, возвращающий `200 OK` с текстом `OK`. Подключён через `include`, проверен синтаксис, выполнен reload. Проверены access/error-сообщения через `docker logs`.

### Практика 10. Сохранение конфигурации через bind mount
Файлы `default.conf` и `health.location` скопированы из контейнера в `~/docker-lab/nginx-config/`. Контейнер пересоздан с read-only bind mount каталога конфигурации. После пересоздания успешно проверены `/health` и `/`.

## Созданные и изменённые файлы
- `~/docker-lab/nginx-config/default.conf`
- `~/docker-lab/nginx-config/health.location`
- `~/devops-learning/docker/day14.md` — учебный журнал

## Итог дня
Освоены запуск и диагностика Nginx в Docker, HTTP-статусы, конфигурация виртуального сервера, reload, логи, endpoint проверки здоровья и сохранение конфигурации вне контейнера.

**Результат:** Nginx работает на порту `8080`, `/health` возвращает `200 OK` и `OK`, конфигурация сохраняется после пересоздания контейнера.
