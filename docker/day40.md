# День 40 — GitHub Actions: управление CI matrix

## Цель
Научиться исключать комбинации из CI matrix, управлять поведением заданий при ошибках и проверять восстановление pipeline.

### Практика 1. Проверка существующей матрицы
- Проверен workflow `first-ci.yml`.
- Матрица использует окружения testing и staging, Python 3.11 и 3.12.
- Исходные комбинации успешно выполнялись в GitHub Actions.

### Практика 2. Исключение комбинации
- Добавлен параметр `strategy.matrix.exclude`.
- Исключена комбинация staging + Python 3.11.
- Запуск #52 завершился успешно.
- Вместо четырёх комбинаций выполняются три.

### Практика 3. Настройка fail-fast
- Добавлен параметр `fail-fast: false`.
- Проверены изменения через `git diff --check` и `git diff`.
- Создан коммит и выполнен push.
- Запуск #53 завершился успешно.

### Практика 4. Проверка поведения при ошибке
- Временно добавлена команда `exit 1` для testing + Python 3.11.
- Запуск #54 получил ожидаемый статус Failure.
- Остальные комбинации матрицы успешно завершились.
- Подтверждено действие `fail-fast: false`.

### Практика 5. Восстановление CI
- Удалена искусственная ошибка.
- Исправлена лишняя пустая строка в конце YAML.
- Изменения отправлены в GitHub.
- Запуск #55 завершился успешно за 18 секунд.
- Все три комбинации матрицы прошли проверки.
