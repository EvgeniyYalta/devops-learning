# День 12 — Docker: build cache, слои и оптимизация

## Цель

Изучить Docker build cache, слои образов, влияние изменений файлов на пересборку, `.dockerignore` и жизненный цикл контейнера.

## Практики

### 1. Docker build cache

Повторно собран образ `my-nginx:1.0`. Docker использовал существующий cache для базового слоя `nginx` и слоя `COPY`.

### 2. Просмотр слоёв образа

С помощью `docker history` изучена структура `my-nginx:1.0` и последовательность слоёв базового образа и собственного `COPY`.

### 3. Изменение исходного файла

Изменён `index.html` для проверки поведения build cache при изменении файла, используемого инструкцией `COPY`.

### 4. Пересборка после изменения

Повторная сборка показала, что слой `FROM nginx:latest` остался в cache, а изменённый `COPY` был выполнен заново.

### 5. Сравнение слоёв

С помощью `docker history` подтверждено появление нового верхнего слоя после изменения `index.html`.

### 6. Проверка размеров образов

С помощью `docker images` изучены размеры `my-nginx:1.0`, `nginx:latest` и `ubuntu:24.04`.

### 7. Проверка метаданных образа

Через `docker image inspect` проверены ОС, архитектура и размер образа `my-nginx:1.0`.

### 8. Проверка изменённого образа

Запущен контейнер `my-nginx-cache-test` из обновлённого образа. Через `curl` подтверждено новое содержимое страницы.

### 9. Проверка конфигурации контейнера

Через `docker inspect` проверены используемый образ, состояние контейнера и опубликованный порт `8082`.

### 10. Проверка логов

Через `docker logs` проверен запуск Nginx и успешный HTTP-запрос `GET /` с кодом `200`.

### 11. Жизненный цикл контейнера

Контейнер остановлен с кодом `0`, затем повторно запущен. После запуска Nginx снова успешно отдавал изменённую страницу.

### 12. Проверка Dockerfile

Подтверждено содержимое Dockerfile:

- `FROM nginx:latest`
- `COPY index.html /usr/share/nginx/html/index.html`

### 13. Создание `.dockerignore`

Создан `.dockerignore` с правилами исключения:

- `.git`
- `*.log`
- `tmp/`

### 14. Проверка `.dockerignore`

Созданы тестовые `.git`, `test.log` и `tmp/`. Сборка показала уменьшенный build context — исключённые файлы не передавались в Docker build context.

### 15. Очистка временных ресурсов

Удалены тестовые файлы, временный контейнер `my-nginx-cache-test` и временный образ `my-nginx:ignore-test`.

## Итог дня

Изучен механизм Docker build cache и связь изменений исходных файлов с пересборкой слоёв. На практике проверены Docker layers, `docker history`, `docker image inspect`, жизненный цикл контейнера, `.dockerignore` и build context.

## Созданные и изменённые файлы

- `dockerfile-practice/.dockerignore`

## Результат

Образ `my-nginx:1.0` успешно пересобран и проверен после изменения исходного файла. Docker build cache работает корректно, ненужные файлы исключаются через `.dockerignore`, временные ресурсы после практик удалены.
