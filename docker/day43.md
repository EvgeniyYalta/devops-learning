# День 43 — GitHub Actions: timeout-minutes

## Цель дня

Освоить ограничение времени выполнения заданий CI,
проверить принудительную остановку задания и восстановить
рабочую конфигурацию workflow.

### Практика 1. Проверка существующего workflow

Проверили текущую конфигурацию first-ci.yml.
Изучили структуру задания basic-check и шага Verify CI recovery.
Проверили состояние локального репозитория.

### Практика 2. Настройка timeout-minutes

В задании basic-check добавили параметр:

```yaml
timeout-minutes: 5
```

Установили максимальное время выполнения задания в 5 минут.
Проверили изменения и отправили их на GitHub.

### Практика 3. Проверка GitHub Actions

Проверили запуск workflow №64.

Результат:
- Общий статус: Success.
- basic-check выполнен успешно.
- Все три задания матрицы выполнены успешно.
- validation выполнен успешно.
- staging-check пропущен согласно условию.
- Время выполнения: 15 секунд.

### Практика 4. Проверка срабатывания тайм-аута

Уменьшили timeout-minutes до 1 минуты.
Добавили искусственную задержку sleep 90
в шаг Verify CI recovery.

Проверили запуск workflow №65.

Результат:
- basic-check остановлен по тайм-ауту.
- Общий статус: Cancelled.
- Независимые задания матрицы выполнены успешно.
- Зависимые задания пропущены.
- GitHub подтвердил превышение лимита времени.

Убедились, что continue-on-error не отменяет
ограничение времени выполнения задания.

### Практика 5. Восстановление CI

Вернули timeout-minutes: 5.
Удалили искусственную задержку sleep 90.
Восстановили исходное содержание Verify CI recovery.

Проверили запуск workflow №66.
Общий статус: Success.
Время выполнения: 16 секунд.

## Созданные и изменённые файлы

- .github/workflows/first-ci.yml — настройка тайм-аута.
- docker/day43.md — журнал обучения.

## Итог дня

- Освоили параметр timeout-minutes.
- Проверили принудительную остановку задания.
- Изучили взаимодействие timeout и continue-on-error.
- Проверили поведение зависимых и независимых jobs.
- Восстановили рабочий CI pipeline.

Результат: CI работает успешно, ограничение времени
выполнения basic-check составляет 5 минут.
