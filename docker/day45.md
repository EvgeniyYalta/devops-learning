# День 45 — GitHub Actions: max-parallel

## Цель дня

Изучить управление количеством одновременно выполняемых заданий матрицы GitHub Actions и проверить влияние параллелизма на продолжительность CI.

### Практика 1. Проверка существующей матрицы

- Проверена конфигурация задания matrix-check.
- Изучены существующие параметры strategy, matrix, exclude и fail-fast.
- Установлено, что матрица содержит три комбинации окружений и версий Python.

### Практика 2. Настройка max-parallel

- Добавлен параметр max-parallel: 1.
- Установлено ограничение на одновременное выполнение заданий матрицы.
- Изменения отправлены на GitHub.

### Практика 3. Проверка последовательного выполнения

- Проверен запуск GitHub Actions №76.
- Все три задания матрицы успешно выполнены.
- Продолжительность workflow составила 22 секунды.
- Итоговый статус: Success.

### Практика 4. Настройка параллелизма

- Параметр max-parallel изменён с 1 на 2.
- Разрешено одновременное выполнение двух заданий матрицы.
- Проверены изменения конфигурации.
- Изменения отправлены на GitHub.

### Практика 5. Проверка итоговой конфигурации CI

- Проверен запуск GitHub Actions №77.
- Итоговый статус: Success.
- Продолжительность workflow составила 16 секунд.
- Время выполнения сократилось на 6 секунд относительно предыдущего запуска.
- Сохранена настройка max-parallel: 2.

## Итог дня

- Изучен параметр max-parallel.
- Освоено ограничение параллельного выполнения заданий матрицы.
- Проверены последовательное и параллельное выполнение.
- Проведено сравнение продолжительности двух запусков CI.
- Работоспособность workflow подтверждена.
